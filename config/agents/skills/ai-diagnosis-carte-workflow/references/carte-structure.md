# カルテ構成の正典（フェーズ5）

テンプレートは `assets/carte-template.xlsx`（ホームプラザ様向け 2026-06-27 版を原本として採用）。ユーザーが別の元ブックを指定した場合はそちらを優先し、このファイルの構成定義と食い違えば元ブックに従う。

## シート構成（4シート）

1. `AI診断カルテ` — 冒頭に会社概要1行（業種／拠点・人数／主要業務／現状特徴）＋カテゴリ見出し行＋メイン診断表。
2. `プラン概要` — プラン分類 `01 AI研修` / `02 AX支援` / `03 AIソリューション開発`。
3. `技術的前提・注意事項` — API・既存システム連携、データ品質、個人情報、法的判断、「AIは補助で最終判断は人間」、段階導入。
4. `メモ` — 営業向けの補足・注意点。

## メイン診断表の列（12列）

```text
No / 緊急度 / 重要度 / 優先度 / 業務内容・課題 / 概要 /
改善後の年間削減効果 / 対応しやすさ・着手しやすさ / 同業比較スコア /
対応プラン / 詳細アプローチ / 技術的注意点・前提条件
```

- 優先度は星評価と A/B/C を併用: `A（即着手可能）` / `B（準備後着手）` / `C（要件整理が必要）`。
- 緊急度・重要度・同業比較スコアは星評価（例: `★★★`、`★★★☆☆`）。同業比較は外部根拠がなければ断定を弱める。
- 診断項目はカテゴリ（`1. ○○` の見出し行）でグルーピングし、項目は `1-1`、`1-2` の枝番で振る。

## 書き込み時の落とし穴（実物で確認済み）

- **No列の `1-1` 形式は Excel が日付に自動変換する**（テンプレート実物でも `2026-01-01` に化けている）。No列は**必ずテキスト書式（`@`）で書き込む**か、openpyxl なら文字列を明示的にセットして `number_format = '@'` を設定する。
- **カテゴリ見出し行・タイトル行は横方向にセル結合されている**。結合セルの**左上以外に書き込むとエラーになる**（過去の生成作業で実際に発生）。書き込みは結合範囲の左上セルだけに行う。
- 書式・セル結合・列幅・行高・折り返し設定はテンプレートからコピーし、**値だけ**差し替える。スタイルの再構築はしない。
- 診断行の文章セルは折り返し前提の長文。列幅を変えず、文量をテンプレートと同程度に保つ。

## 検証（フェーズ8で使う最低ライン）

- 4シートが存在する。
- 診断表のヘッダー12列が一致する。
- 旧顧客名（テンプレ由来の `ホームプラザ` など）が顧客可視セルに残っていない。
- No列が日付化していない。
